# Jo OS

Jo OS is Tony's persistent operations platform.

## Control plane
Supabase/Team V4 owns durable jobs, worker state, verification, approvals, events and publishing handoffs.

## Workers
Jo orchestrates. Steve owns Missed Call Rescue. Tom owns Unmapped America. Mary owns Cigar 30 merchandise/KDP. Jeff owns email/admin support.

## Execution rule
Assignment is not execution. A job is complete only after its required evidence passes verification.

## Tom free production path
Production package -> FFmpeg render -> MP4 -> Jo Core production registration -> technical/visual/audio QA -> publish handoff -> publisher-worker -> YouTube API verification -> Team V4 closure.

Secrets stay in GitHub Actions/Supabase secret stores and never in source control.
